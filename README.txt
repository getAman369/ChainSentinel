# Open DAOHub

## Project Description
Open DAOHub is a decentralized platform built on blockchain, enabling communities to form Decentralized Autonomous Organizations (DAOs) with ease. It fosters transparent proposal management, voting, and decision-making.

## Project Vision
To empower everyday users and organizations to self-govern and co-create value through trustless and decentralized decision-making systems.

## Key Features
- DAO membership via wallet address
- On-chain proposal creation and voting
- Ownership-controlled proposal updates

## Future Scope
- Add support for weighted voting
- Governance token integration
- DAO treasury and fund allocation modules
